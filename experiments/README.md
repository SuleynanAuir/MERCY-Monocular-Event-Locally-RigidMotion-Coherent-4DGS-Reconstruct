以下分析基于本页对应的归档实验，仅解释已有结果，不修改原始数值，也不新增未实测的结论。具体版本、原始指标和来源可点击上方物品名称查看。

### 1. 各项指标分别说明什么？

- **PSNR：像素重建误差。** 越高表示渲染图与参考图的均方误差越小。它采用对数尺度，应使用 dB 差值描述提升，不宜把 dB 数值直接换算成“画质提升百分比”。全图背景占比会影响分数，因此还要结合前景 PSNR，避免背景拟合良好掩盖物体细节不足。
- **SSIM：图像结构相似程度。** 越高通常表示局部亮度、对比度与结构更接近参考图。它适合辅助观察边缘和纹理恢复，但不能单独证明三维结构正确或所有视角都清晰。
- **LPIPS：感知特征差异。** 越低表示两张图在所用感知网络的特征空间中更接近。它与 PSNR 关注的差异不同，因此可能出现 PSNR 更高、LPIPS 却更差的候选，需要结合实际画面判断。
- **IoU：前景轮廓覆盖重合度。** 越高表示渲染轮廓与参考前景区域更一致。它不直接衡量表面颜色或内部纹理。本项目部分参考掩码由 RGB 背景阈值得到，暗色材质可能被漏分，因此该数值不能等同于独立几何真值精度。
- **缺失率与部件缺失率：参考区域未被覆盖的程度。** 越低越好，但只覆盖参考前景仍不够：向外膨胀的渲染也可能降低缺失率，所以应同时检查 IoU。部件指标需要对应的部件参考，缺少标注时不能由整体缺失率替代。
- **事件指标：运动引起的亮度变化是否一致。** 事件 L1 越低、事件余弦与极性一致率越高，通常表示预测与参考事件更接近；静默区变化越低，表示无事件区域中的额外变化更少。这些解释依赖源报告的事件响应标定与时间窗口，不能仅凭 RGB 分数推断事件质量。
- **延迟、FPS、点数与显存：计算代价。** 点数较多不必然更精细；离线渲染更快也不等于浏览器播放更流畅。需要确认分辨率、采样倍率、硬件及计时是否包含传输、编码和缓存。报告中的进程峰值显存不能全部归因于一个版本。

### 2. 九个物品的结果应怎样解读？

**Lego。** 当前表对应 200 个采样时刻的六面实验。推荐 V3 在该报告中兼顾了图像拟合与轮廓覆盖，适合作为这一实验协议下的保留版本。这里的结果不属于后续独立 Hybrid FVV 训练，不能用于断言动态铲头、铲臂在任意视角下都达到相同质量。

**Fan。** 推荐周期外观 V3，主要考虑旋转过程中的外观与事件表现。历史候选的 IoU 略高，说明不同优化目标存在取舍；当前选择并不意味着它在所有单项指标上都最高。本地完整报告已有事件标定结果，应保留这些原始记录，不能因之后服务器缺少事件文件而将其抹去。

**Lamp。** 推荐的是连续表面与覆盖修复版本。它的 IoU 为 `0.966323135146142`，但历史外观候选具有更高的 PSNR。选择当前版本，是优先考虑几何覆盖与整体效果，而不是只追求像素误差最低。不能把旧版较高的 PSNR 与当前版较高的 IoU 拼成一个不存在的模型结果。

**Metronome。** 当前报告的 PSNR 为 `43.245488620437115`，SSIM 为 `0.9950098880132784`，说明在该参考、相机与采样时刻下具有较小的图像差异。但这些高分不能证明它比其他物品更容易或更难重建，也不能代替新视角和独立序列验证。

**Microphone。** 推荐 V3 在对应报告中具有较好的图像相似性和轮廓覆盖。IoU 与图像指标并非同一维度：即使感知差异较小，轮廓边界仍可能存在偏差。保留版本时应共同参考这些指标，而不是以单一 SSIM 或 PSNR 判断完整结构质量。

**Arm。** 推荐 RGB 结构优化 V3，用于改善关节外壳等区域的外观。主报告包含 13 个时刻，其中有训练与选点样本；另有留出验证记录。结果支持在现有源视角下的改善，但不能直接证明所有关节、所有视角或新动画都同样准确。

**Robot。** 推荐新多视角 V3，主表采用原视频的 24 帧审计。IoU 为 `0.6660229905465536`，提示轮廓与参考前景的匹配仍有提升空间；同时，光度代理掩码可能漏掉暗部，不能仅凭此值将差异全部归因于几何缺陷。合成视角的训练、验证和独立角度测试应分别阅读，不能与原视频混合平均。旧 V1/V2 的 12 帧报告也不能直接拼入当前 24 帧对照。

**Gears。** 推荐紧致感知 V3。大位移候选具有更高的 PSNR、IoU，但六面检查发现侧背面齿缘粗糙；当前版本在限制位移后更注重紧致外观，并取得更好的 LPIPS。这体现了“分数更高”和“最终效果更好”并不总是完全一致，选择依据需要同时保留数值与视觉验收记录。

**Rotation。** 当前 V3 在 40 帧主报告中同时表现出较高的 PSNR、SSIM、IoU 和较低的 LPIPS，支持其在本次固定评估条件下的改善。8 个留出时刻也有单独验证，但这些时刻参与检查点选择，因此仍属于验证结果，而不是完全独立的最终测试。

### 3. 为什么每个物品都推荐 V3，却不能声称严格逐级改进？

V3 是各物品被保留的改进阶段名称，不是一个统一算法或统一训练条件。各报告中 V1、V2 的具体含义也可能不同；部分物品的 V1 是已有修正版，V2 是原始高斯，因此数值并不天然满足 V1＜V2＜V3。

本汇总保留原始版本定义和测量值。正确的判断方式是：**在同一物品、同一相机、同一时间范围、同一参考和渲染设置下比较版本**，再结合空间误差、动画与其他视角验收。不同物品的 PSNR 高低不构成统一排行榜，200 个采样时刻也不能与 25 个时刻简单合并成一个“项目总分”。

### 4. 如何看待均值、空间误差图与局部缺陷？

主表中的数值是源报告的汇总值，不能说明每一帧、每一个像素都改善。均值更好时，仍可能存在局部闪烁、遮挡、边缘粗糙或个别时刻退化，需要继续查看逐帧记录和空间误差图。

对于“V3−V2”图，首先要看图例：如果画的是两张渲染图直接相减，它只表示变化，不能判断谁更准确；本项目对应空间图中的有符号误差差值为 **error(V3)−error(V2)**，参考相同 GT。负值表示 V3 的误差更小，正值表示退化。色域、选帧规则和参考图应保持一致，不能通过改变配色范围制造改善印象。

### 5. 当前结果支持哪些结论，还不支持哪些结论？

现有归档支持：在各自已记录的实验条件下，对推荐版本的质量、覆盖、事件一致性及计算代价进行追溯，并说明相对基线的改善或取舍。

现有归档不足以统一证明：所有物品在任意视角下均优于所有历史候选、时间帧之间统计独立、所有指标提升具有统计显著性，或离线渲染速度等同于实时浏览流畅度。Arm、Robot、Gears、Rotation 的部分评估与 RGB 训练或检查点选择存在重叠，这一点需要随结论一同保留。

缺失数据表示未提供或当前无法计算，**不代表零误差、零事件或完美效果**。如需进一步证明泛化，应在训练与选点之外另设固定的新视角、独立时间段或新序列，沿用相同的参考及指标定义再评测。
