# 五场景统一适配实验

本目录比较新建的 **C1 Bind-GS、C2 Align-GS、C3 / A0 MERCY 五场景运动适配版**。它们不是原 Lego 全流程的复现实验，也不是三个外部论文算法的复现。结果仅解释为：给定同一份已有 G0 和运动先验后，运动校正模块对观测一致性的影响。

## 目录

| 目录 | 内容 |
|---|---|
| `01_main_comparison` | 主实验／对照：五场景，C1 固定基线，C2/C3 各三个种子 |
| `02_ablation` | 消融：去 MLP、去事件、去连接约束、去轨迹约束；单种子预算检查 |

## 与原 Lego 方法的差异

| 项目 | 本轮适配协议 |
|---|---|
| 共同初始模型 | 每个场景都使用数据目录中已有的 corrected G0；C1/C2/C3 完全相同，冻结颜色、不透明度、尺度和点数。不是 UI 的原始／修正版资产比较。 |
| C1 | 最近源表面绑定与源动画；没有神经运动参数，因此不进行虚假的 C1 梯度训练。Fan 的解析先验仅从训练 RGB 段辨识。 |
| C2 | 7 参数有界相似变换共轭，校正运动坐标关系；每轴 Euler 角限 ±5°，每轴平移限场景对角线的 ±1%，尺度限 exp(±0.1)。RGB 和可用原始事件共同监督。没有挪用历史 UI V2 的检查点。 |
| C3 | C2 加三层 32 宽 SiLU 局部 MLP；输入部件中心、源运动状态和时间，输出每个刚体组的小幅旋转／位移。默认每轴最多 0.5°、0.1% 场景对角线，受源运动激活包络约束。静止组不变。不是任意逐点变形。 |
| 训练阶段差异 | 本轮 C2/C3 从共同零修正分别训练；C3 的全局校正与局部 MLP 联合接受 RGB＋事件目标。没有逐阶段复现原 Lego「冻结父 V3 后以事件训练局部 MLP」的流程，也不是严格 event-only 支线。 |
| 连接约束 | 从完整已知源动画验证旋转连接候选，使用软间隙保护；**未移植 Lego 的硬 FK／闭环锁定**，必须查看实际间隙。Fan 的轴为解析假设。 |
| 轨迹约束 | 约束叠加后轨迹的三阶差分、关节角三阶差分和幅度偏差，局部 MLP 为辅助。Lego 非刚性橡皮带保留已有局部刚体烘焙近似，不进入局部 MLP。 |
| 几何／外观优化 | 未纳入 Lego 后续补点、表面重建、颜色优化、遮挡补全或 UI 柔光处理。不能把运动适配结果描述为完整 MERCY 的五场景成绩。 |
| 输入曝光 | 既有 G0 的历史训练帧未知；Blender 全段运动显式提供。因此不是未知运动外推、严格未见帧建模或新视角重建泛化证明。 |

所有相机／源动画配准使用已有相机和几何；不使用验证／测试 RGB 来选择方向或改进配准。已有相机的历史校准曝光同样未知。

## 数据与固定划分

仅包含 Lego、Fan、Lamp、Metronome、Microphone 五个完整场景。`data/gaussians` 不作为第六个独立样本。

- 按时间连续 60% / 20% / 20% 划分训练、验证、测试，两个边界各保留隔离帧；事件区间的两个端点必须位于同一段内。
- 渲染背景固定为训练首帧 8 像素边缘的 RGB 中位数，且检查边缘近似均匀：节拍器为 `[69,69,69]/255`，其他四场景为黑色。前景掩膜按与该背景的差定义，保留灰底上的黑色物体。
- 原始事件先检查 NPY 完整字节数、排序、坐标、极性和时长。Fan 事件文件截断，因此 **Fan 为 RGB-only 适配**；不使用事件预览视频替代，不参与 RGB+事件组的合并统计。
- 事件文件的生成来源尚未提供，不能将这些数值称为独立真实事件传感器的验证证据。
- 对四个有效事件场景，仅用训练段搜索 −1/0/+1 帧偏移和三个对数强度下限，并拟合正负对比度阈值。校准参数随后冻结；偏移后的区间也不能越过划分边界。
- Fan 没有 Blender 源动画：仅用训练 RGB 估计轴心、静动分组和恒角速度；验证／测试段使用该解析先验外推，不逐帧读取测试图拟合运动。该输入条件单独披露。
- Fan 训练段诊断显示恒速先验欠拟合：与训练 RGB 极坐标相关估计的角度 RMSE 为 20.43°，且训练后段出现反转。该估计不是独立运动真值，但误差已远超亚度级局部补偿范围。保留既定五场景成绩并将其标记为先验失配案例，不据测试画面重选先验，也不将其成绩解释为局部 MLP 能力的干净比较。证据见 [训练段诊断](01_main_comparison/visualization/fan_prior_diagnostic.png)。
- 三个训练种子为 17、29、43，每次 200 次更新，C2/C3 同一采样顺序和训练观测预算。每 40 步验证一次，也允许选择零步基线；测试集不参与选择。
- 这是固定预算适配对照，不宣称已达到各方法最优或收敛上限。CUDA 原子归约可能存在非确定性，保留代码哈希和环境信息。

## 十项指标的实际定义

固定训练配置：Adam；相似变换学习率 0.01，MLP 学习率 0.003；梯度范数上限 1。每次更新采样一个训练区间，观测目标为 `全画面 RGB L1 + 0.5 × 固定前景 RGB L1 + 0.03 × 事件相对 L1`；Fan 和去事件消融移除事件项。验证使用五个固定区间的相同观测目标，不加入训练正则项。

C3 的软连接项权重为 5，惩罚相对源先验新增的间隙，距离除以 `0.001 × 场景对角线`。三维和角轨迹三阶差分项权重各为 0.002，分别除以源轨迹的均方能量，分母下限为 1e−9 和 1e−7；幅度保持项权重 0.1，幅度差除以 `0.01 × 场景对角线`。C2/C3 另有权重 0.0001 的相似变换原始参数平方均值正则。各场景使用同一组权重，未根据测试成绩逐场景调参；实现见 `training.py::regularizer`。

| 指标 | 本轮定义及范围 |
|---|---|
| RGB L1 ↓ | 测试帧、原始 RGB、统一训练背景、[0,1]、全画面三通道平均绝对差；不使用网页截图。另存前景分项。 |
| PSNR ↑ | 每帧 `−10 log10(MSE)` 后平均；动态范围为 1，单位 dB。精确匹配的无限值单独记录，不任意截顶。 |
| SSIM ↑ | 每通道计算，Gaussian σ=1.5、population covariance、data_range=1，再平均。 |
| 留出事件相对 L1 ↓ | 测试区间渲染对数亮度差与原始正负计数拟合变化之差的绝对值总和，除以该区间观测变化绝对值总和；原生对数差后 8×8 均值池化，再对可观测区间平均。 |
| 事件通过区间 ↑ | 测试区间通过数／全部有效划分区间；同时检查余弦、极性、无支持变化和相对 L1。证据不足区间判失败，不从通过率分母移除。阈值和失败原因逐段保存。 |
| 可见缺失率 ↓ | **图像前景覆盖代理**：参考 RGB 与固定背景的逐通道绝对差均值 >8/255 的像素中，渲染 alpha <0.5 的比例，跨帧累加分子／分母。不是物理表面缺失面积，与背景同色的区域不可由此度量。 |
| 背面缺失率 ↓ | `N/A`：没有独立、已配准的背面参照；不能把作为输入的 Blender 几何或另一版模型当独立真值。 |
| 最大关节间隙 ↓ | 测试段源连接候选的同一静止枢轴，经两侧变换后的最大距离；单位为该场景坐标单位。Fan 仅检查假设转轴。 |
| 角 jerk ↓ | 已验证旋转连接的相对四元数在源轴上的 twist 角，展开后做三阶差分 / dt³，RMS；rad/s³。候选不足则 N/A。 |
| 三维 jerk ↓ | 每个刚体运动组固定最多 64 个 G0 点，同样的点 ID、同样的测试时刻，三阶差分 / dt³ 的欧氏 RMS；场景单位/s³。Lego 的非刚性橡皮带不计入该采样集，不把动态组的取样密度变化混入指标。 |

保留 `frame_metrics`、`event_metrics`、采样 IDs、原始分子／分母、检查点哈希。表中跨种子报告均值与样本标准差；C1 的一次固定基线不虚构标准差。场景坐标单位可能不同，统计时将三维 jerk 和间隙除以各自固定的场景对角线，不直接平均不同坐标尺度的原值。

事件通过判据沿用项目的诊断规则：强变化阈值为 0.01，池化图上的支持邻域半径为 1；余弦至少 `max(0.35, 0.7 × 参考余弦)`，极性一致率至少 `max(0.65, 参考值 − 0.12)`，无支持变化最多 `min(0.25, 参考值 + 0.12)`，相对 L1 最多 `min(1.1, 参考值 + 0.35)`。这里的参考值来自同一区间 RGB 与事件的自检，三种方法共用；这是一项依赖参考数据的诊断指标，不是物理正确性的证明。

消融的「去事件」同时去除训练和检查点选择中的事件项，属于监督流程消融；其他变体沿用完整方法的选择准则。「去轨迹约束」同时去除三维 jerk、角 jerk 和幅度保持项。Fan 本来就没有事件监督，因此不重复运行没有实际差异的去事件变体。敏感度实验只改变已经训练好的局部 MLP 输出强度，固定 0、0.25、0.5、0.75、1 五档，在验证段测量，不据此重选测试成绩。

效率图中的训练墙钟包含验证，排除共同的输入审计、源动画导出／绑定、模型加载和最终测试。C1 的该耗时仅为初始验证，没有优化更新。显存为 PyTorch 峰值已分配内存，不等同于整卡占用；推理耗时在二十帧预热后重复五轮，不把重复计时当独立训练实验。

推理计时使用包围完整运动＋GS 渲染调用的 CUDA events。它包含调用内的提交间隙以及 Lego 烘焙橡皮带的缓存读取／搬运可能造成的耗时，排除监督视频解码、SSIM 和结果写盘；不是纯 CUDA kernel 基准，也不是网页端到端播放帧率。

SSIM 参数参照 [scikit-image 官方文档](https://scikit-image.org/docs/stable/api/skimage.metrics.html)。统计采用配对场景 bootstrap 区间、精确双侧符号翻转检验和 Holm 校正；假设与小样本限制随结果保存。四个同条件事件场景无法提供强显著性证据，重复帧不能扩大样本量。

小样本 bootstrap 区间仅作探索描述；即使它不跨零，也不能替代精确配对检验和多重比较校正。

`05_significance/precision_control.json` 用 Fan 的解析恒角速度先验检查有限差分精度。其理论角 jerk 为零，原生 float32 旋转和采样会产生非零数值底噪，因此不能将接近该量级的变化描述为真实消抖。三维 jerk 还包含正常圆周运动的贡献，本身不是纯粹的抖动指标。

## 命令行运行

需要项目 CUDA 光栅器、PyTorch、NumPy、SciPy、OpenCV、scikit-image、matplotlib、plyfile、ffprobe，以及可读取源文件的 Blender。Blender 自动脚本执行始终禁用。建议先运行 `python -m unittest experiment.test_protocol -v`。

```bash
python -m experiment.run audit --data /path/to/data \
  --output experiment/01_main_comparison/server_inventory.json
python -m experiment.run prepare \
  --inventory experiment/01_main_comparison/server_inventory.json \
  --blender /path/to/blender
python -m experiment.batch --steps 200 --seeds 17 29 43
python -m experiment.batch --section ablation --steps 200 --seeds 17
python -m experiment.followups
python -m experiment.run report
python -m experiment.audit_results
python -m experiment.provenance
```

`prepare` 的大缓存存于 `01_main_comparison/prepared/`；不要提交原始视频、事件、PLY 或解码数组。检查点仅包含校正网络权重，必须与对应 prior 和原始 G0 哈希一致后才可重放。已有输出不会静默覆盖，失败记录和日志需保留。

以上全流程命令用于没有已有结果的新工作副本；本轮已经保存的队列与输入均为冻结记录。复现时建立新的工作副本和输出目录，不删除或覆盖本轮结果。只重新生成本轮图表可运行 `python -m experiment.run report`。

执行中发现并纠正了节拍器的背景配置：初始代码误用黑底，其相关运行完整保留于 `01_main_comparison/invalid_runs/background_fix/`，不进入主表和统计。`background_audit.json` 记录训练帧证据和四个黑底场景不受影响的等价性；节拍器的三种方法全部按修正后的共同配置重新运行。背景修正不是 C3 的方法收益。
