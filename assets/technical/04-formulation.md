# 数学表示与优化目标

本页描述当前 Lego 融合实现的表示、坐标关系、观测目标与局部辅助网络。公式用于统一符号；具体损失权重、开放参数和采样分辨率以对应脚本及运行记录为准，不能把不同历史分支合成一个未经运行的训练目标。

## 高斯表示与坐标约定

令规范状态高斯为 `G_i = (x_i, q_i, s_i, alpha_i, c_i)`：中心 x 为三维向量；q 为旋转四元数；s 为三轴尺度；alpha 为不透明度；c 为颜色参数。当前动画转移代码采用 `w,x,y,z` 四元数顺序。PLY 内尺度、不透明度等可能保存为优化参数空间，加载时应使用模型的激活规则，不能把原始字段直接当成物理量。

物理尺度组成协方差 `Sigma_i = R(q_i) diag(s_i^2) R(q_i)^T`。给定相机与当前高斯，渲染器输出 RGB／灰度和覆盖信息。相机内参、外参、图像尺寸与坐标轴方向共同决定投影；只对齐画面中心不能保证尺度和深度正确。

`A` 表示 Blender 世界坐标到高斯坐标的配准，`M_j(t)` 表示 Blender 部件 j 的世界矩阵。采用列向量时：

```text
D_j(t) = A M_j(t) M_j(0)^(-1) A^(-1)
x_i(t) = R(D_j(t)) x_i(0) + T(D_j(t))
q_i(t) = q(R(D_j(t))) ⊗ q_i(0)
```

代码的 NumPy 行向量写法等价于 `points @ R.T + T`。不能混淆行列约定，也不能把绝对 Object 矩阵直接再次作用于已经处于世界坐标的 G0。该路径在首帧固定为恒等变换。

## 基础运动和校正的区别

基础动画由 `ArticulatedBaker` 生成。共享校正模型在已有运动上改变坐标对齐，其设计是相似变换的共轭关系，而非任意逐点位移。`RigidMotionCorrection` 用有界参数控制旋转、平移和尺度；这不意味着所有高斯的显示尺度也会被学习。

时间模型用 Catmull–Rom 控制量生成连续修正；分组模型为运动组增加受限自由度；硬关节模型则通过层级运动保持连接。上述模型是配置选项，不应将它们的修正无条件全部累加。连续参数化有助于时间插值，但不能单独保证真实运动、无抖动或关节闭合。

来源：[基础动画](../../utils/articulated_motion.py)、[校正模型](../../utils/event_refinement.py)、[关节模型](../../utils/joint_refinement.py)。

## 视频与事件的观测模型

对视频帧时刻 t_k 和 t_(k+1)，统计每像素区间内正负事件数 `N+_k(u)`、`N-_k(u)`。在相应符号约定下，期望对数亮度变化为：

```text
E_k(u) = C+ N+_k(u) − C− N−_k(u)
L_k(u) = log(max(I_render(t_k,u), epsilon))
D_k(u) = L_(k+1)(u) − L_k(u)
```

C+、C− 与 epsilon 取自标定，事件窗口与视频偏移也必须一致。这里是区间累计的图像空间约束，不能由单一窗口唯一恢复三维运动；正负事件抵消、低纹理、遮挡与亮度模型误差都会影响可观测性。

时间校正训练先渲染、取 log 差，再池化到多个比较尺度。由于 log 非线性，`pool(log I)` 与 `log(pool I)` 不能互换。更换图像大小、亮度下限或标定后，历史阈值与分数也不能直接沿用。

## 校正阶段的优化目标

[时间校正训练](../../scripts/events/refine_lego_temporal.py) 的多尺度事件项由相对 L1 和方向相似度构成，另有极性、视频灰度、前景覆盖及参数正则。概念表达为：

```text
L_event = sum_s w_s [ ||P_s(D) − E_s||_1 / max(||E_s||_1, 1)
                      + lambda_cos (1 − cosine(P_s(D), E_s)) ]
L_total = L_event + lambda_pol L_polarity + lambda_rgb L_image
          + lambda_cov L_coverage + L_regularization
```

`P_s` 为实际比较尺度上的池化。分母下限、强事件掩码、有效区域和每项权重应按脚本实现读取。上式描述该训练分支，不规定所有审计指标也使用相同归一化。

视频项比较当前渲染与对应灰度帧；覆盖项惩罚目标前景中亮度不足的区域，以降低通过缩小运动或缺失前景来获得较低事件误差的风险。正则限制校正幅度与时间变化，但它们都是先验，不能替代观测证据。

## 关节约束

刚体组内所有高斯接受同一个旋转和平移。树状关节通过共享连接点和父子变换传递，避免各部件自由平移导致分离。闭环及相关祖先的残差自由度按实现限制，不能直接套用无约束树结构求解。

验证量包括关节两侧连接点距离、旋转正交性和同部件点对距离偏差。关节连接不保证渲染表面无孔；表面缺失需要单独检查。模型没有因此获得质量、惯性、受力或碰撞求解能力。

## 局部 MLP 残差

当前 `LocalJointMLP` 以冻结基础轨迹为条件。关节特征包含归一化角度、角度正余弦、归一化速度、归一化关节位置及组身份。多尺度残差基由基础轨迹生成，并保持约定的时间锚点。

```text
a_jk(t) = tanh(MLP(f_j(t))_k) × gain / K
Delta_theta_j(t) = group_gain_j × sum_k B_jk(t) a_jk(t)
```

B 为残差基，K 为基数量。网络末层零初始化提供零补偿起点；gain、分支增益和角度上界共同限制修正。补偿通过关节层级变成部件变换，再作用于高斯，而不是直接任意移动每个高斯。

训练采用事件代理与叠加后轨迹平滑目标，候选再使用实际高斯渲染对训练事件复核。最终留出指标不参与这轮选模；继承的基础模型与标定仍须记录历史数据暴露。来源：[局部 MLP](../../utils/v4_local_mlp.py)、[训练器](../../scripts/deformation/train_v4_local_mlp.py)。

## 平滑性与外观变化

离散三阶差分反映轨迹加速度变化，可作为 jerk 指标的基础。报告应固定采样间隔、角度展开、尺度归一化和聚合范围；未经时间单位换算的离散值不能直接称为物理单位 jerk。

角度更平滑不保证所有三维点轨迹更平滑；层级旋转、杠杆长度与位置归一化均会改变结果。全局、预先定义局部和实际启用局部三种范围不得混合。

几何补全、颜色、不透明度和尺度变化会改变成像与预测事件，即使部件运动不变也需重新审计。显示阶段的伪彩色、白模照明和去噪不应输入训练指标。
