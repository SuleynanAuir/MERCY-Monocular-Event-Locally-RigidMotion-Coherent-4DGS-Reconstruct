# 实验计划与结果填写模板

配合 [全项目实验设计](../../technical/12-experiment-plan.md) 使用。每组比较复制一份模板，每次运行使用独立记录；`待测` 表示尚未测量，`N/A` 表示不适用，二者都不能填成 0。以下表格不是已有成绩。

## 单次运行记录

| 字段 | 填写内容 |
| --- | --- |
| run_id／实验 ID | 例如 lego_X11_seed00；关联总计划中的 ID |
| 分支／场景／序列 | Lego 主线、event-only、Fan 或 Lamp；序列来源 |
| 方法与状态 | 方法、配置版本；planned／running／completed／failed／invalid |
| 研究问题 | 本次唯一变化、比较对象及允许支持的结论 |
| 代码身份 | Git commit、未提交 diff 文件及 SHA256、外部实现版本 |
| 输入身份 | G0、RGB、事件、相机、动画、部件／绑定、几何先验各自路径和 SHA256 |
| 观测与先验权限 | 实测／合成事件；Blender 动画／网格／材质；手工标注 |
| 父产物 | 父模型、校正、几何层、外观层、MLP 路径及 SHA256；继承的数据暴露 |
| 数据划分 | split manifest、train／val／test 时间和帧 ID、保护带、窗口长度 |
| 初始化与标定 | 读取哪些样本、拟合哪些参数；G0 来源是否接触测试信息 |
| 随机性 | Python／NumPy／Torch／CUDA seed、确定性选项、配对规则 |
| 训练配置 | 全部损失权重、学习率、迭代、点数政策、网络规模、冻结参数和选优规则 |
| 主指标与保护条件 | 主指标名称、方向、实际意义阈值、容许 RGB／结构／相位退化 |
| 运行命令 | 完整命令文件、实际配置文件；不要只保存默认值 |
| 硬件与环境 | GPU 型号／数量／显存、CPU、RAM、驱动、CUDA、Torch、渲染器、精度 |
| 渲染配置 | 分辨率、颜色空间、背景、相机／时间表、ROI、GS／Mesh／混合、滤波 |
| 成本 | 预处理／训练／导出／评估时间、GPU 小时、峰值显存、完整包大小 |
| 输出身份 | checkpoint、序列、清单、审计、逐帧指标、视频及各自 SHA256 |
| 失败记录 | OOM／数值异常／来源不符／验收失败；发生阶段与重试关联 ID |
| 验收状态 | 完成训练与通过科学验收分开；未通过的候选仍保留 |
